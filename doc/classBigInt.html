BigInt BigInt::bigPow10 ( unsigned short  pow)
static

Returns 10 raised to the power of pow (10 ^ pow).

The result is a new BigInt with the decimal representation "1" followed by pow zeros.

Parameters
powThe exponent of 10, i.e. the number of zeros following the leading "1" in the decimal representation of the result.
Returns
