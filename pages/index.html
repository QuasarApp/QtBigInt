QtBigInt - Arbitrary-sized integer class for C++

Arbitrary-sized integer class for C++ with build system support for Qt (qmake) and CMake. Powered by minigmp 6.1.2 for high performance, with no additional dependencies other than the standard library.

Features

  • No additional dependencies other than the standard library

  • Build system support: qmake and CMake

Quick example

#include <bigint.h>

BigInt big1 = 1234567890, big2;
big2 = "9876543210123456789098765432101234567890";

std::cout << (big1 * big2 * 123456).getString() << "\n";
// Output: 1505331490682966620443288524512589666204282352096057600
